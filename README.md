# 🔐 SecureVault — Zero-Trust Cloud File Storage Platform

A full-stack, production-ready secure cloud storage platform implementing 
zero-trust security architecture.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Cloud:** AWS S3
- **Security:** AES-256, JWT, bcrypt, 2FA

## Features
- 🔐 AES-256 File Encryption
- ☁️ AWS S3 Cloud Storage
- 🛡️ Two Factor Authentication (2FA)
- 📊 Real-time Security Dashboard
- 🔗 Secure File Sharing with Expiry Links
- 🚨 Intrusion Detection & Audit Logs
- 📧 Email Security Alerts
- 👤 Role-Based Access Control
